About the data

Windy API Cameras and images are sourced from the Windy Webcams API v3, which aggregates feeds from operators across the Alps (ski resorts, mountain huts, panorama cams, observatories). Filtered to active Swiss mountain cams above a 1,000-view threshold and sorted by viewer count.
Refresh Thumbnails point to Windy’s “current” image proxy — updated on the cam operator’s schedule (typically every few minutes). Click View Live to open the full webcam page on windy.com with controls, timelapse, and weather overlays.
