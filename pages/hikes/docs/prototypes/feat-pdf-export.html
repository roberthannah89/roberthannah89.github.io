Print / PDF Export

"Print this page" suitable for taking on the trail in paper form. Pure CSS, no JS deps, works over file://.

DONE

Demo

Open augstmatthorn.html, click "⎙ Print / PDF" button top-right of hero, save as PDF

Browsers may block file:// printing — if so, serve from ~/venvs/dev/bin/python -m http.server 8000 in the pages/hikes/ dir.

Approach: pure CSS, not JS-PDF

  • The codebase already had an 80-line @media print stylesheet — most hide/restyle work was done.
  • Pages load via file:// where fetch() silently fails — any html2canvas/jsPDF pipeline that captures Leaflet tiles breaks.
  • CSS gets ~95% of the way there. No ~600 KB runtime dependency.
  • The one real gap (Leaflet map prints unreliably) is solved with a self-contained inline SVG snapshot generated from window.TRACK — no tile requests, perfect at any zoom.

Printed page layout (A4, 1.2 × 1.4 cm margins, black-on-white)

  • Top strip: page URL (mono) on the left, "Printed from page generated YYYY-MM-DD" on the right
  • Hero: flattened to bold title + subtitle, hairline rule under
  • Quick Facts table — distance / gain / time / trailhead / grade pill
  • Route Map: inline SVG, GPX polyline projected to 800×520 viewBox (~11 cm tall), Start / Summit / End markers, "N↑" north arrow, 1 km scale bar
  • Elevation profile: existing SVG, restyled black-on-grey, hourly weather badges retained
  • Route Details prose (SAC terrain & safety description)
  • Getting There: transit links rendered as bulleted plain-text URLs (Google Maps drive / transit, SBB)
  • Field Reference: trailhead / summit / waypoints with WGS84 coords (mono)
  • Emergency footer: single bold-bordered box — EMERGENCY · Rega 1414 · EU 112 · what3words: ///___.___.___

Hidden in print: photos, weather grid, live Leaflet map, 3D widget, lightbox, webcams, trip reports, social/share, site footer, the Print button itself.

Files touched (in worktree)

  • templates/hike_page.j2.html — Print button, print-only header strip, <svg id="print-map">, emergency aside
  • templates/_assets/hike_page.css — .print-btn screen styles; updated @media print
  • templates/_assets/hike_page.js — renderPrintMap() IIFE projecting window.TRACK to SVG
  • auto-synced routes/_assets/hike_page.{css,js} + regenerated routes/augstmatthorn/augstmatthorn.html

Polish left for later

  • SVG snapshot has no basemap — just a polyline on flat grey. Adequate for "did I miss the junction?" with the coords; better with a swisstopo static-image PNG pre-baked at render time.
  • North is assumed straight up — fine for ~all Swiss hikes; could matter for a strongly NE–SW traverse.
  • what3words placeholder is empty — needs an API key + render-time call to fill trailhead/summit slots.
  • "Generated on" date is page-render date, not print date — a beforeprint hook could swap it.
  • Page breaks tuned minimally — page-break-inside: avoid on sections, but on shorter hikes the layout lands awkwardly. Real-print a few + adjust.
  • Integrate the QR code prototype — drop it into .print-header so a phone can re-open the page in the field.
