Zindlenspitz — 3D prototype (Mapbox GL JS v3)

Mapbox Standard Satellite style with built-in 3D terrain + atmosphere. Right-click + drag to tilt & rotate. GPX track in red.

Library: Mapbox GL JS v3. Uses the public docs demo access token — fine for prototyping. For production, sign up free at account.mapbox.com and replace mapboxgl.accessToken (free tier: 50K map loads/month).
