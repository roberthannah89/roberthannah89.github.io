Implementation notes

  • No API keys required — every source is public.
  • Overpass overlays rate-limit easily. Capped at 2000 results server-side, per-day localStorage cache, plus a tiny committed sample-data/osm-fallback.js (~12 well-known points each) that auto-loads on HTTP 429.
  • Snow line is "prototype-honest." No DEM in-browser to draw a real isohypse — ribbon shows the median freezing-level across all peaks (peak tempMax + 6.5°C/km lapse rate). make weather can swap in direct ICON-CH2 values.
  • Generic toggleLazyOverlay registry in command-center.js — adding the 8th overlay is just one more entry in the array.
  • Existing toggles intact — hikes off→on cycle still changes marker count (28→37→28), webcams shows 80 cameras.
