About Open-Meteo

Open-Meteo is a free, open-source weather API that aggregates forecasts from multiple global and regional models: MeteoSwiss ICON-CH1 (1 km resolution over Switzerland), ECMWF IFS, NOAA GFS, and DWD ICON-EU among others. No API key is required for non-commercial use, CORS is enabled so requests work directly from file:// pages, and forecasts can be elevation-corrected to any altitude — critical for mountain peaks where station-based forecasts under-report temperature drops and overestimate clear conditions.

This prototype showcases the killer feature: model comparison. When all models agree, confidence is high. When they diverge, that spread is the forecast uncertainty — useful for deciding whether to commit to a long alpine day, or wait for a clearer signal.
