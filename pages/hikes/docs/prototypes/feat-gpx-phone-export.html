Six pill-style buttons in a wrapping flex strip, each with icon + bold label + tiny sub-line. Ships on all 75 hikes.

The honest research finding

No hiking app ships a documented app://import?url=…/track.gpx scheme that works cross-platform. Komoot's "Send to Komoot" is OAuth-gated; Gaia's URL-scheme request has been open since 2019; only Locus Map (Android) has a real intent filter. SchweizMobil GPX import is gated behind paid Plus.

Don't fake "Open in <app>" buttons — pretending creates broken expectations. The reliable cross-platform path is <a download> → OS share-sheet → user picks Komoot / OsmAnd / Organic Maps / SchweizMobil / Gaia / AllTrails. Every installed app surfaces.

The six buttons

  • Download GPX (primary, red) — <a download> with mime application/gpx+xml. Triggers OS app picker.
  • Share (mobile-only, feature-detected) — Web Share API level 2 with the GPX file attached on iOS Safari + recent Chrome. Short-circuits the download step.
  • Copy link — page URL to clipboard.
  • Trailhead — geo:lat,lon on Android, maps.apple.com/?q=… on iOS, Google Maps directions everywhere else. UA-detected.
  • SchweizMobil — map.schweizmobil.ch?E=…&N=…&zoom=10 with WGS84→LV95 conversion. Works free without paid Plus.
  • QR code — lazy-rendered SVG (vendored qrcode-generator, MIT), desktop-to-phone hop. Note: overlaps with the dedicated QR prototype — deduplicate before merging.

Below the strip: a <details> "What app should I use?" with brief per-app guidance.

Recommended verdict

  1. Web Share API is the highest-value mobile addition — one tap → app picker with the actual GPX file. Invisible on desktop.
  2. SchweizMobil web map is the highest-value Swiss-specific touch — canonical map, free to view.
  3. QR is the highest-value desktop-to-phone bridge — many users plan on a laptop.
  4. Don't add fake deep-links. Honest is better than slick.

Future enhancement

If/when a hike has a known SchweizMobil national-route number (e.g. Hardergrat is part of Trail 13), link directly to that route page — that IS effectively a deep link for the Swiss audience. Would need a national_route_id field in data.json.
