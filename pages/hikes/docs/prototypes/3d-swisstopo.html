Zindlenspitz — 3D prototype (swisstopo embed)

Embedded map.geo.admin.ch in 3D mode at the summit. Right-click + drag to tilt. Scroll to zoom.

GPX track overlay requires the file to be served from a public URL. Once this site is hosted, append &layers=KML||https://<your-domain>/routes/zindlenspitz/zindlenspitz.kml to the iframe src (GPX must be converted to KML first — swisstopo's viewer doesn't ingest GPX directly).
