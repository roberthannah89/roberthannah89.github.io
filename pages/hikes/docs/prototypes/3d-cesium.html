Zindlenspitz — 3D prototype (CesiumJS)

Curved-earth 3D globe with Cesium World Terrain (high-res quantized-mesh DEM) + Bing satellite. Right-click + drag to tilt. GPX track in red.

Library: CesiumJS. Uses the bundled Cesium Ion default token (rate-limited; for production, sign up free at ion.cesium.com and replace Cesium.Ion.defaultAccessToken below). World Terrain free tier: 5GB/mo. Bundle size ≈ 3 MB JS + 600 KB CSS.
