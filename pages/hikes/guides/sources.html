Sources & credits

Every hike page on this site stitches together data from many authoritative sources — photos, route descriptions, GPX geometry, elevations, tiles, weather, avalanche bulletins, and transit timetables. Here they all are, with credit to the people and organizations who make the underlying data.

📸 Photographers

Every photo on this site was taken by a Swiss Alpine Club member and contributed to the SAC Route Portal. Photographers retain full copyright; credit appears per photo on every hike page. Photos are hotlinked from SAC's CDN — SAC serves the bytes, this site just references them in context.

✍️ Route authors

Route descriptions, difficulty ratings, terrain notes, and segment timings are written by SAC contributors — freelance photographers, mountain guides, guidebook authors — and published on the SAC Route Portal. Their bios come directly from SAC's author sidebar.

🗺 Trails & base maps

swisstopo

National topographic maps (WMTS tiles), the 3D elevation API, the Wanderwege trail network with SAC grading, canton polygons, and hillshade / slope overlays. The single most-relied-on data source on this site after SAC.

Live tiles from wmts.geo.admin.ch; build-time API calls to api3.geo.admin.ch.

→ Buy maps in the swisstopo shop

OpenStreetMap

Alternate base tile layer, plus Overpass queries for the peak catalog and per-trail SAC scale (sac_scale, trail_visibility) used by the difficulty guide. Every hut, peak, water point, and POI in the Command Center comes from OSM.

Live tiles from tile.openstreetmap.org; build-time Overpass queries.

→ Contribute an edit to OSM

SAC Route Portal

Primary source for every hike — route geometry (via the SAC layer API), difficulty grades, ascent/descent times, waypoints, terrain notes, per-photo captions, and route-author biographies.

Cookie-gated; scraped at build time via scripts/scrape_sac_route_page.py.

→ Join the SAC

GADM

The Swiss national boundary polygon used to clip and shade maps. Downloaded once, bundled into swiss_border.js, then served locally forever.

One-off build-time download from geodata.ucdavis.edu.

→ GADM data page

SchweizMobil (Wanderland)

National / regional / local hiking route badges shown in the difficulty guide, plus outbound links to Wanderland's route pages.

Hotlinked badge SVGs from images.schweizmobil.ch.

→ Support SchweizMobil

⛰ Terrain & 3D

CesiumJS + Google Photorealistic 3D Tiles

The "Load photorealistic 3D" view on each hike page. Cesium renders the browser-side globe; Google supplies the photogrammetric mesh (the same 3D data behind Google Earth). Requires a user-supplied Google Maps Platform key.

Loaded in-browser inside an iframe; keyed access to tile.googleapis.com.

AWS Terrain Tiles (Terrarium)

Global 30 m DEM served as PNG heightmap tiles, used as the terrain source in the photorealistic 3D prototype. Free public dataset hosted by AWS as part of the Open Data program.

Hotlinked from s3.amazonaws.com/elevation-tiles-prod inside the 3D prototype.

☁️ Weather

Open-Meteo

The 7-day peak forecast on every hike page. Open-Meteo serves MeteoSwiss's ICON-CH2 / ICON-CH1 models to the public for free, no key required — one of the most generous public data services in existence for the alpine forecasting world.

Live browser fetch from api.open-meteo.com; also cached daily for the Command Center.

→ Donate or subscribe

MeteoSwiss

The upstream numerical models (ICON-CH2 / ICON-CH1) behind Open-Meteo, plus outbound links from every hike page and the weather guide to their hazards, föhn index, and inversion forecasts.

Data reaches this site indirectly via Open-Meteo; direct outbound links for hazards and specialised forecasts.

Meteoblue

Deep-linked "detailed forecast" button on each hike page (uses the peak's lat/lon), and the multi-model comparison links in the weather guide.

Outbound links only — no data is fetched from Meteoblue.

Windy.com

Nearby webcam thumbnails around each peak (via the Windy Webcams v3 API), plus outbound links to Windy's rain radar. Thumbnails are hotlinked from Windy's own image proxy.

Build-time API fetch → cached list; runtime thumbnails hotlinked from imgproxy.windy.com.

→ Windy API

❄️ Avalanche

SLF / WhiteRisk

The daily national avalanche bulletin — danger polygons, ratings, snow surface descriptions — shown as an overlay in the Command Center. Data follows the EAWS CAAML v6.0 standard.

Scheduled daily fetch from aws.slf.ch (winter-only; empty May–Oct).

→ About SLF

🚆 Transit

SBB

Deep-linked timetables on every hike page — trailhead station and (for point-to-point routes) the arrival station too. URLs are pre-computed at build time from SAC-scraped station names.

Outbound deep-links; no data pulled at runtime.

→ Buy a GA / Half-Fare card

transport.opendata.ch

Live connection lookups and station autocomplete for the "Getting There" transit widget on every hike page. Free, keyless wrapper over SBB / search.ch data operated by opendata.ch.

Live browser fetch from transport.opendata.ch.

→ opendata.ch

search.ch timetable

Per-row deep-links from the transit widget — search.ch accepts more precise time-anchoring parameters than SBB's own URL scheme.

Outbound links only.

Google Maps & Calendar

Driving / transit directions to the trailhead, and "Add to Google Calendar" for chosen transit legs.

Outbound links only; the optional embedded Google Map needs a user-supplied API key.

📚 Software libraries

Leaflet + Leaflet.markercluster

The main map on the index, every hike page, and the Command Center. Simple, well-documented, dependency-free — the reason the maps just work.

MapLibre GL JS

WebGL-accelerated vector maps used for the 3D hike view and the peak viewer. Open-source fork of Mapbox GL kept community-driven.

GoatCounter

Privacy-friendly page-view counter on every page. No cookies, no personal data collected, no ads.

→ Support GoatCounter

💛 How to support the sources

If this site is useful, the single most valuable thing you can do is support the organizations that publish the underlying data. In rough order of "how much they contribute to what you're using here":

  • Join the Swiss Alpine Club (SAC) — every route, photo, and description on this site started as SAC member work. Membership funds hut maintenance, rescue, and the route portal itself.
  • Buy from the swisstopo shop — the paper 1:25 000 maps, the Swiss Map Mobile app subscription, or their guidebooks. swisstopo's public API is generously open; supporting the shop keeps that possible.
  • Become a Rega patron (CHF 40/year) — covers your own potential rescue, and keeps Swiss air-rescue independent of insurance politics.
  • Contribute to OpenStreetMap — fix a mislabeled trail, add a fountain, tag a hut. The peak catalog and trail grading here depend on OSM data.
  • Donate to Open-Meteo — the free weather API powering the forecasts on every hike page.
