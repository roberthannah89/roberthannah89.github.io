Planning a hike

Find a route on the SAC portal, download the GPX, load it into SwissTopo or Komoot, and take the train to the trailhead. See Apps & resources for the full tool list.

Using the SAC Route Portal

The SAC Route Portal has 6,000+ curated routes. Filter by activity, difficulty (T1–T6), duration, and region.

Reading the map

  • Red trails = T1–T3 (mountain hiking). Blue trails = T4–T6 (alpine hiking).
  • Red houses = SAC huts. Green peaks = hiking peaks. Purple peaks = alpine peaks.

Peak → route workflow

  1. Click a peak icon on the map.
  2. Choose a route from the list. "Archived routes" are from historical texts — treat with extra care.
  3. Route page has description (usually German — use browser translate), waypoints, time estimates (accurate for a fit person), and a public transport link to the trailhead.
  4. Download the GPX. Import into SwissTopo or Komoot for offline navigation — cell reception is unreliable in the mountains.

SAC huts

153 huts bookable through the SAC website. For multi-day hikes, string huts together and book in advance.

Transport

Almost every trailhead is reachable by public transport. Use SBB — it covers trains, PostBus, and many gondolas in one ticket. The GA / Swiss Travel Pass is worth it if you hike regularly.
