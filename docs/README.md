## Scripts

All build scripts live in `scripts/`:

| Script | Purpose |
|--------|---------|
| `render_hike.py` | Render all hike pages from `data.json` files |
| `add_hike.py` | Add or update a hike from a compact JSON spec (fast path) |
| `new_hike.py` | Scaffold a new hike directory with template `data.json` |
| `build_hike_gpx.py` | Build GPX route from coordinates (uses OSM Overpass) |
| `check_hiking_docs.py` | Validate instructions are in sync with script CLI flags |
| `download_images.py` | Download and optimize hike images |
| `validate_images.py` | Validate image dimensions and formats |
| `make_topo_map.py` | Generate topographic maps (experimental) |

**Usage:** `make <target>` from repo root. See `make help` for all targets.

## Data

- **Hike instances:** `pages/hikes/routes/<slug>/`
  - `<slug>.data.json` — source of truth for each hike
  - `<slug>.html` — generated page
  - `<slug>.gpx` — route track
  - `<slug>.track.js` — Leaflet map data

- **Generated files:**
  - `pages/hikes/index.html` — gallery page (generated by `render_hike.py`)
  - `pages/hikes/guides/` — educational pages (difficulty, gear, planning, weather)
  - `pages/hikes/routes/_assets/` — CSS/JS shared across all hike pages

- **Config:**
  - `templates/templates/hike_data.schema.json` — JSON schema for validating `data.json` files

## Workflow

### Adding a New Hike

1. **Scaffold:** `make new slug=myshort name="My Hike" region="Region" ...`
2. **Edit:** Fill in `pages/hikes/routes/myshort/myshort.data.json`
3. **Build GPX:** `make gpx slug=myshort peak="Peak Name" bbox="..."`
4. **Render:** `make render slug=myshort --probe`
5. **Publish:** Push to GitHub (CI renders full site automatically)

### Updating Existing Hike

1. **Edit:** Update `pages/hikes/routes/<slug>/<slug>.data.json`
2. **Render:** `make render slug=<slug>`
3. **Push:** GitHub CI will build the full site

## CI/CD

- **Trigger:** Push to `main` branch
- **Workflow:** [.github/workflows/pages.yml](../.github/workflows/pages.yml)
- **Steps:**
  1. Validate hike data (`render_hike.py --validate-only`)
  2. Check documentation consistency
  3. Render all pages
  4. Deploy to GitHub Pages
